# M4 reference, valuation and evaluation API

M4 retains every M3 endpoint and adds three read-only experiment projections:

```text
GET /v1/experiments/{experimentId}/references
GET /v1/experiments/{experimentId}/valuations
GET /v1/experiments/{experimentId}/evaluations
```

References expose their frozen kind and instrument, immutable replacement rule, entry status, comparison availability, initial-distribution hash and canonical M1 portfolio. There are exactly two for each configured scenario.

Valuations return append-only common-time scenario checkpoints. Each checkpoint contains the agent and both references, their post-accrual portfolios, mark and liquidation values, cash, reservations, in-transit and blocked value, payables, source hashes and data-quality reasons.

Evaluations contain integer-only descriptive metrics and nullable reference differences. `null` means unavailable; it must never be rendered as zero. The three sizes are labeled correlated policy views with effective independent sample count `1`. M4 enables no inference and no real-capital eligibility.
