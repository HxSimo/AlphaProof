# M0 API

- `GET /health/live`: process liveness, independent of database availability.
- `GET /health/ready`: checks database migration readiness; 503 with `DATABASE_UNAVAILABLE` on failure.
- `GET /v1/profiles`: validated configuration bundle hash, profile provenance, disabled status, dependency blockers and limitations. Response is checked by the web using the shared schema.

There are no M0 mutation endpoints. A successful catalog response is not experiment acceptance, an execution receipt or a funding permission. The full v0.3 API and injected-signer SDK are planned in M3; see `pnpm plan M3` and the authoritative API/signing reference. Public production authentication, quotas and TLS are delivered with the external mutation flow. Local Docker ports bind localhost.
