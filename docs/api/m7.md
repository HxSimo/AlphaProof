# M7 operations and demo API

All responses are canonical backend objects; the web performs no accounting. The existing M3–M6 read APIs remain available. The running API now requires an operator bearer secret for all control mutations, including agent registration and experiment start. `POST /v1/experiments/:id/actions` continues to require its EIP-712 envelope instead. A missing operator secret disables control writes, not reads or proof replay.

| Route                                 | Contract                                                                                                                       |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `GET /health/operations`              | `OperationsSnapshot` v1; health, queue age, heartbeat history, incidents, rejected ingress, policy hash; missing age is null   |
| `GET /v1/experiments/:id/incidents`   | Append-only `IncidentRecord` v1 array in durable time/ID order                                                                 |
| `POST /v1/incidents`                  | Operator-authenticated `IncidentInput`; exact duplicate no-op, changed identity conflict, cross-experiment resolution rejected |
| `POST /v1/experiments/:id/stop`       | Operator-authenticated `{reason: string}`; closes intake only after active actions reconcile and preserves portfolio hashes    |
| `GET /v1/experiments/:id/dashboard`   | `DashboardResponse` v2; v1 retained in schema catalog, v2 allows a null commitment while pending                               |
| `GET /v1/experiments/:id/demo-export` | Latest immutable `DemoSession` v1 for that experiment; old revisions remain in append-only storage                             |
| Web `GET /exports/:id`                | Server-side download of the API's demo export; unavailable data returns 503                                                    |

HTTP 401 uses `AUTH_REQUIRED`, 429 uses `RATE_LIMITED` with `Retry-After` or `QUOTA_EXCEEDED`, and malformed input is `INVALID_SCHEMA`. A stop while an action is active is `SCENARIO_BUSY`. Legacy profile drift is `VERSION_DRIFT`; terminal receipt or plan mutation is `OPERATION_CONFLICT`. Public error responses omit provider URLs, database details and credentials.

See [M7 operations](../runbooks/m7-demo-operations.md) for quota, recovery and key-separation details. Retained sessions contain public synthetic test signatures, not a service-held agent signing key. A downloaded publication receipt is retained evidence; current canonical-chain verification uses the separately gated RPC command.
